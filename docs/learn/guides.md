#### AutoCam 1.0 Release Walkthrough

The introductory video for AutoCam's first release.

{% embed url="https://www.youtube.com/watch?v=se_65uZgON4" %}

* Explains the fundamental concepts of **Record**, **Path**, and **Rig**.
* **Applies to 2.1.1?**\
  The core Record → Path → Rig workflow is unchanged.\
  Ignore the Rig Mode switch and the Speed slider - timing is keyframed on the **Progress** slider now. Treat Tracking as **Manual Aim**, and note that the object called **LookAt** in the video is now called **Aim**.\
  _&#x46;or more details, refer to the_ [_**Changelog**_](../updates/changelog/)_._

#### AutoCam 2.0 Release Walkthrough

The updated introductory video for AutoCam's 2.0 release.

{% hint style="warning" %}
**Recorded on AutoCam 2.0.**\
The workflow still holds, but the interface has moved on: the panels are now Source / Path / Rig / Output, the Rig Mode switch and Speed sliders are gone, and timing is keyframed on Progress.\
\
Since **2.1.1**, the rig's aim controls are also renamed - the handle you drag is **Aim** (it was "LookAt") and the pivot behind it is **Gimbal** (it was "Aim"). **Show Path Direction** moved to Preferences → Viewport.\
\
See the [Changelog](../updates/changelog/) for the full list.
{% endhint %}

### Where to start with Pro

If you've just installed AutoCam Pro, these are the shortest paths to seeing what it does:

| Try this                                                   | Where                                                                    |
| ---------------------------------------------------------- | ------------------------------------------------------------------------ |
| Fix a take that came out 90% right, live at playback speed | [**Steer Path**](features/path.md#realtime-path-steering-pro)            |
| Get your recorded pacing back on a clean path              | [**Inherit Original Speed**](features/rig.md#inherit-original-speed-pro) |
| Build a push-in with a rack focus from two stills          | [**Camera Morph**](features/source.md#camera-morph-pro)                  |
| Make a seamless product turntable                          | [**Loop** + **Repeat Laps**](features/path.md#loop-pro)                  |
| Keep the camera on a moving subject                        | [**Lock to Target**](features/rig.md#lock-to-target-pro)                 |
| Cut between two camera moves                               | [**Segments**](features/rig.md#segments-pro)                             |
| Send the shot to Maya or Unreal                            | [**Export**](features/output.md#export-pro)                              |
