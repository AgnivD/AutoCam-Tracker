### What's being worked on next

Plans, not promises - the GitHub project is always the current truth.

#### AutoCam Pro

* **Follow Target** tracking and **Multi-Target markers**.
* **Batch export** - Export selected cameras to a folder with automatic naming.
* Blended hand-offs between **Segments** (1.0.0 does hard cuts only).

#### AutoCam Free

* **Speed Multiplier + Sync Tracking** - live pace rescale, targeted at the 3.x line.
