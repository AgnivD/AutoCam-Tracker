# Changelog

AutoCam ships as two editions on **two separate version lines**. Pick the one you're running - **Preferences → Add-ons → AutoCam → About** tells you which.

***

| **AutoCam Pro**  | **1.0.0** | 2026-08-04 | [Full changelog →](autocam-pro.md)  |

***

### How the two lines relate

**AutoCam Pro is not a continuation of Free's 2.x numbering.** It started its own line at 1.0.0.

The two editions share a core. Pro 1.0.0 is built on the shared core of Free 2.1.1, so everything in the Free changelog up to 2.1.1 - the renamed aim controls, the resized rig handles, the Preferences reorganisation - is also true of Pro 1.0.0. The Pro changelog covers only what Pro adds on top.

When a shared-core change lands, both lines get it: Free as a 2.x release, Pro as a 1.x release.

{% hint style="info" %}
This project uses **semantic versioning** - **MAJOR.MINOR.PATCH** <mark style="color:$info;">(</mark>_<mark style="color:$info;">e.g., AutoCam Free 2.1.1</mark>_<mark style="color:$info;">).</mark> Documentation covers **v2.0.0** onwards for Free, and **v1.0.0** onwards for Pro.
{% endhint %}
